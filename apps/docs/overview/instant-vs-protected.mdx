Every listing offers one or both ways to pay. The creator picks which ones when they list.

| | Instant | Protected |
| - | - | - |
| Where the money goes | Straight to the creator | Into the on-chain escrow |
| Content arrives | After the payment is in a block (17–31 s measured) | After the lock is in a block (30–50 s measured) |
| If nothing is delivered | No recourse | Refunded automatically after the submit deadline |
| If the wrong thing is delivered | No recourse | Dispute, settled by the arbiter |
| Minimum price | 1 tADA | 5 tADA |
| What the creator receives | The full price, at once | The price minus 10% or 1.5 tADA (whichever is more), after the escrow releases |

## Which one to pick

- **Instant** suits cheap prompts from creators you already trust. It is faster and the creator gets everything.
- **Protected** suits everything else. The money only reaches the creator if the prompt you get is the one that was listed.

<Note>
  The protected minimum exists because running the escrow costs Simpuru about 1.5 tADA per sale in transaction fees (lock, result, withdrawal and the creator payout). Below 5 tADA that cost would eat most of the price.
</Note>
